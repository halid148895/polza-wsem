# Библиотека Мединского курса

Отдельный статический сайт. БАДР не изменялся. Публикация не выполнялась.

## Предпросмотр

Из папки `library`:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:8765. Для проверки с телефона в одной доверенной сети запустить сервер с `--bind 0.0.0.0` и открыть IP компьютера с портом 8765. Локальная ссылка 127.0.0.1 работает только на компьютере, где запущен сервер. Двойной щелчок по index.html не подходит: каталог загружается через HTTP.

## Добавление книг

Единый каталог — `dist/catalog.json`. Каждый уровень содержит `id` и массив `books` в порядке отображения. Книга содержит уникальный `id`, `kind`, `title` с ключами `ru/en/ar`, `sourceUrl`, `pdf` и необязательное `note` с тремя переводами.

- `sourceUrl` — исходная онлайн-книга HTML. Для неё показывается «Открыть».
- `pdf` — относительный путь к реальному PDF в `dist/pdfs/`. Для него показываются «Открыть» (новая вкладка) и «Скачать PDF» (скачивание того же файла через download).
- `kind: rules` и `kind: dictionary` попадают в дополнительные материалы; `source` и `quran` — в исходную программу.
- Названия и пояснения нужно заполнить на всех трёх языках. PDF не переводится.
- Один путь PDF может использоваться в нескольких карточках. Файл 3–4 хранится один раз.
- Чтобы добавить словарь: скопировать файл в `dist/pdfs/`, затем заменить `pdf: null` у `l1-dictionary` (или другого уровня) на путь.
- Четыре PDF уроков Корана находятся в программе ibn-saud.

Интерфейс: `dist/app.js`; оформление: `dist/style.css`. Сборка и установка зависимостей не нужны. Подойдут любое статическое размещение по HTTPS и любой путь размещения, включая подкаталог. Настройки языка и масштаба хранятся только в localStorage браузера. Маршруты находятся в URL после #, поэтому серверу не нужны правила SPA fallback.

Для предпросмотра используется HTTP. Внешние книги требуют интернета. Открытие PDF зависит от встроенного просмотрщика устройства; кнопка скачивания всегда указывает на локальный PDF того же сайта.

## Программы и выпуск

В catalog.json верхний уровень теперь содержит программы с id, title и levels.
Чтобы добавить уровень, внесите в levels объект с числовым id, локализованным title
и массивом books. Для материала добавьте запись в books нужного уровня и положите
PDF в dist/pdfs. Для новой категории используйте существующий тип source,
dictionary или rules. Пустой массив отображается сообщением об отсутствии материалов.

Для публикации используется отдельный проект Firebase Hosting. Firebase публикует
папку dist согласно firebase.json. После выбора адреса создаётся собственный проект
Firebase и подключается публикация из ветки main отдельного репозитория GitHub.
Для следующих выпусков достаточно обновить каталог и PDF в этом репозитории.
